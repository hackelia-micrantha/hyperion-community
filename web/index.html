Engineering in practice

Infrastructure as code

OpenTofu/Terraform modules for a synthetic reference environment and Incus instances. Inspect the locked-provider example, including synthetic disk and NIC configuration. Schema validation, not live provisioning.

Host bootstrap

Ansible/K3s automation with non-mutating defaults and explicit, checksum-verified binary acquisition. Verified with syntax checks, lint and check mode.

Kubernetes security

Digest-pinned workload, restricted Pod Security, disabled service-account token automount, default-deny network policy and a Kustomize overlay.

GitOps delivery

Pinned Flux tooling and documented immutable-source consumption. Reconciliation into a live cluster is not yet qualified by the public suite.

Reproducible CI/CD

Hosted, read-only GitHub Actions with immutable action references and the same mise task interface used locally. Includes OpenTofu, TFLint, Kubeconform, Trivy and Checkov.

Infrastructure security

Trust-boundary analysis, publication review, provenance checks and automated leakage detection with regression tests.

Architecture and trade-offs

Layered ownership. OpenTofu/Terraform defines infrastructure, Ansible handles bootstrap, Kubernetes defines workloads, and Flux provides the intended reconciliation boundary. Read the architecture overview.

Explicit effects. The verification path operates on synthetic inputs, not live infrastructure. The public Incus example checks the provider schema without planning or applying changes.

Bounded authority. Public CI is read-only and does not need private deployment credentials. The public repository is independently inspectable without access to private operational source.

Verify from a fresh clone

Use a disposable checkout and install mise. The hosted CI contract runs on Ubuntu 24.04.

git clone https://github.com/hackelia-micrantha/hyperion-community.git
cd hyperion-community
mise install
mise run doctor
mise run lint
mise run ci

Checks cover provider-schema validation, Ansible check mode, rendered Kubernetes manifests, security scanning and publication-boundary tests. Public tools and dependencies are downloaded; infrastructure is not deployed.

Current maturity: inspectable source reference with synthetic validation. End-to-end K3s and Incus lifecycle, live Flux reconciliation, production provisioning and backup/restore are not qualified by this suite. See the draft source-alpha notes; no release has been published.

Public/private trust boundary

Public examples are purpose-built reference inputs, not redacted copies of live environments.

Live inventories, cluster overlays, credentials, encrypted deployment material, topology, private integrations and deployment-specific composition remain private.

Components are published after provenance, security and validation review. Read the publication boundary and review criteria.
